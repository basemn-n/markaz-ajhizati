# مركز أجهزتي — نسخة أولية 0.3.0

مشروع أولي بواجهة عربية قابلة للتثبيت (PWA)، وتطبيق Android Studio باستخدام Kotlin وJetpack Compose، وخادم تجريبي FastAPI.

## الواجهة المنشورة
مجلد `web/` يحتوي على واجهة ويب عربية متجاوبة، وملفات PWA. يمكن نشر الواجهة على Render كـ Static Site باستخدام مجلد النشر `web`.

## تنبيه مهم
هذه نسخة تجريبية وليست نظام تحكم عن بُعد فعليًا. واجهة الويب تحفظ بيانات العرض في المتصفح فقط، والخادم التجريبي لا يحتوي على مصادقة وتفويض وتشفير إنتاجي. لا تستخدمه للرسائل الخاصة أو التحكم الفعلي قبل إضافة الحماية وموافقة المستخدم.

## تطبيق Android
افتح مجلد المشروع في Android Studio. يتطلب Android SDK 35 وJDK 17. لم يتم إنشاء APK أو اختبار البناء ضمن هذه النسخة.

## خادم API مع تسجيل دخول
راجع `server/DEPLOY.md` لإعداد خدمة API منفصلة على Render. لا تنشئ خدمة API بمجرد نشر الواجهة الثابتة. لا تستخدم بيانات حقيقية قبل إعداد `MARKAZ_AUTH_SECRET` وتخزين دائم واختبار الخدمة.

## تشغيل خادم API محليًا
```bash
cd server
python -m venv .venv
pip install -r requirements.txt
uvicorn main:app --reload
```
افتح `http://127.0.0.1:8000/docs`.

## نشر واجهة الويب على Render
راجع `RENDER_DEPLOY.md`. نشر الواجهة وحدها لا يفعّل المراسلة الحقيقية أو التحكم عن بعد.
